Installation

To start using this library, there are only a couple simple steps:

  1. Import the library in your build.gradle

 compile "org.graceframework:scaffolding-core:6.3.0-SNAPSHOT"

  1. Register the scaffolding core bean configuration ScaffoldingBeanConfiguration

 scaffoldingBeanConfiguration(ScaffoldingBeanConfiguration)
